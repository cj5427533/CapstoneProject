## 🔄 데이터 흐름도

### 1. 쇼핑몰 검색 플로우

```
[사용자] 
  ↓ URL 입력
[React Frontend]
  ↓ POST /api/shops/search
[Main Backend]
  ↓ normalizeUrl()
  ↓ Redis 캐시 확인
  ├─ 캐시 Hit → [응답 반환]
  └─ 캐시 Miss ↓
[Supabase]
  ↓ 쇼핑몰 정보 조회
[Main Backend]
  ↓ Redis에 캐시 저장
  ↓ JSON 응답
[React Frontend]
  ↓ 화면 업데이트
[사용자]
```

### 2. 피싱 탐지 플로우

```
[사용자]
  ↓ URL 입력
[React Frontend]
  ↓ POST /api/phishing/detect
[Main Backend]
  ↓ 피싱 탐지 요청
[Phishing Detection Service]
  ↓ URL 분석
  ├─ 도메인 검증
  ├─ SSL 검증
  ├─ 리다이렉트 분석
  └─ 콘텐츠 분석
  ↓ 모델 추론 요청
[Phishing ML Model]
  ↓ 딥러닝 모델 추론
  ↓ 피싱 확률 점수 반환
[Phishing Detection Service]
  ↓ 점수 계산 및 종합
  ↓ JSON 응답
[Main Backend]
  ↓ 결과 반환
[React Frontend]
  ↓ 피싱 경고 표시
[사용자]
```

### 3. 가짜 리뷰 탐지 플로우

```
[사용자]
  ↓ "가짜 리뷰 분석" 클릭
[React Frontend]
  ↓ POST /api/ai/detect-fake-reviews
[Main Backend]
  ↓ 리뷰 데이터 조회
[Supabase]
  ↓ 리뷰 목록 반환
[Main Backend]
  ↓ AI 분석 요청
[AI Analysis Service]
  ↓ 리뷰 텍스트 전처리
  ↓ OpenRouter API 호출
[OpenRouter AI]
  ↓ Claude 3.5 Sonnet 분석
  ↓ 결과 반환
[AI Analysis Service]
  ↓ 결과 처리 및 캐싱
[Supabase]
  ↓ ai_analysis_cache_entries에 저장
[AI Analysis Service]
  ↓ JSON 응답
[Main Backend]
  ↓ 결과 반환
[React Frontend]
  ↓ 결과 표시
[사용자]
```

## 🏗️ 마이크로서비스 구조

### 서비스 목록

| 서비스 | 기술 스택 | 포트 | 역할 |
|--------|----------|------|------|
| **Main Backend** | Node.js + Express | 3001 | 메인 API 서버, 게이트웨이 역할 |
| **Phishing Detection** | Node.js + Express | 3002 | 피싱 탐지 전담 서비스 |
| **Phishing ML Model** | Python + TensorFlow | 8000 | 딥러닝 모델 서빙 |
| **AI Analysis** | Node.js + Express | 3003 | AI 분석 전담 서비스 |

### 서비스 간 통신

| 통신 경로 | 프로토콜 | 방향 | 설명 |
|----------|---------|------|------|
| React ↔ Main Backend | HTTPS/REST | 양방향 | API 요청/응답 |
| Main Backend ↔ Supabase | HTTPS/PostgreSQL | 양방향 | 데이터 조회/저장 |
| Main Backend ↔ Redis | TCP/Redis Protocol | 양방향 | 캐시 읽기/쓰기 |
| Main Backend → Phishing Service | HTTPS/REST | 단방향 | 피싱 탐지 요청 |
| Phishing Service → ML Model | HTTP/gRPC | 단방향 | 모델 추론 요청 |
| Main Backend → AI Service | HTTPS/REST | 단방향 | AI 분석 요청 |
| AI Service → OpenRouter | HTTPS/REST | 단방향 | AI API 호출 |
| Main Backend → File Storage | HTTPS/S3 API | 양방향 | 파일 업로드/다운로드 |
| Main Backend → External APIs | HTTPS/SMTP | 단방향 | SMS/이메일 발송 |

### 학습 데이터

- **피싱 사이트 데이터셋**: 공개 피싱 데이터베이스
- **사용자 신고 데이터**: 플랫폼 내 신고된 피싱 사이트
- **정상 사이트 데이터**: 신뢰할 수 있는 쇼핑몰 데이터
- **데이터 증강**: URL 변형, 도메인 변형 등

### 모델 배포

- **GCP AI Platform / Vertex AI**: 관리형 ML 서비스
- **또는 별도 Python 서버**: Flask/FastAPI로 모델 서빙
- **API 엔드포인트**: `/predict` (POST 요청)
- **응답 형식**: JSON (피싱 확률, 위험도 등급)

## 🔐 보안 아키텍처

- **SSL/TLS**: 모든 통신 암호화
- **JWT 인증**: 토큰 기반 인증
- **API Gateway**: 요청 검증 및 라우팅
- **Rate Limiting**: API 호출 제한
