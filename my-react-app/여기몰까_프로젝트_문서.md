# 여기몰까(Here Mall Ka): 쇼핑몰 신뢰도 분석 플랫폼 프로젝트 문서

> **최종 업데이트**: 2025년 11월 17일  
> **문서 버전**: 2.0.0  
> **프로젝트 버전**: 2.0.0

---

## 1. 프로젝트 개요

### 1.1. 프로젝트명
**여기몰까? (쇼핑몰의 mall)**

부제: 온라인 쇼핑몰 신뢰도 분석 및 피해 사례 공유 플랫폼

### 1.2. 비전 및 목표

**비전**: 누구나 온라인 쇼핑몰의 신뢰도를 투명하게 확인하고, 정보 부족으로 인한 피해를 예방할 수 있는 안전한 전자상거래 생태계를 구축한다.

**목표**:
- 의심스러운 쇼핑몰에 대한 객관적인 신뢰도 분석 리포트 제공
- 사용자 참여를 통한 집단지성 기반의 피해 사례 데이터베이스 구축
- 잠재적 피해자가 발생하기 전에 신뢰도 정보를 신속하게 전파

### 1.3. 타겟 사용자

**주요 타겟**:
- 온라인 쇼핑을 자주 하는 20대 ~ 50대 소비자
- 새로운 쇼핑몰 이용을 고려하는 사용자
- 피해 사례를 경험한 사용자들
- 쇼핑몰 신뢰도에 관심이 있는 소비자

**확장 타겟**:
- 소비자 보호 기관 및 관련 언론사
- 건전한 전자상거래 플랫폼

## 2. 핵심 기능 (Core Features) - 현재 구현 완료

### 2.1. 쇼핑몰 신뢰도 분석 및 리포트 ✅

**검색 기능**: 사용자가 쇼핑몰 웹사이트 주소(URL)를 입력하여 검색
- URL 자동 정규화: `example.com` → `https://example.com`
- 실시간 URL 검증 및 오타 자동 수정
- 웹 스크래핑을 통한 쇼핑몰 이름 자동 추출

**종합 신뢰도 스코어**:
- 안전(초록), 주의(노랑), 의심(주황), 위험(빨강) 4단계 신호등 체계
- 0점에서 100점까지의 점수와 함께 시각적으로 제공

**상세 분석 리포트**:
- **피싱 사이트 검사**: 도메인 연령, SSL 인증서 검증, 리다이렉트 체인 추적, 긴급성 강조 표현, 결제 압박 표현 분석
- **리뷰 신뢰도 분석**: AI 기반 가짜 리뷰 패턴 탐지, 과도한 긍정 표현 분석, 시간적 패턴 분석
- **쇼핑몰 위험도 분석**: 피해 사례 제보, 평점 분석, 도메인 분석, 사업자 분석
- **구체적 위험 지표**: 각 위험 요소별 구체적 근거와 권장사항 제시

### 2.2. 사용자 피해 사례 제보 시스템 ✅

**피해 사례 제보**: 구체적인 피해 사실을 익명 또는 실명으로 제보
- 카테고리별 분류: 배송 문제, 상품 불일치, 환불 문제, 고객 서비스, 사기/피싱, 품질 문제, 기타
- 증빙 자료 첨부: 계약서, 입금 내역, 고객센터 대화 기록 등 파일 업로드 (최대 10개, PNG/JPG, 10MB 이하)
- 증빙 유형별 신뢰도 가중치 적용
- 신고 상태 관리: pending(대기), approved(승인), rejected(거부)

**사용자 평점 시스템**: 해당 쇼핑몰 이용 경험을 바탕으로 별점(1-5점)과 리뷰 작성
- 비회원도 평점 및 리뷰 작성 가능
- 회원 작성 시 사용자명 표시

### 2.3. AI 기반 분석 시스템 ✅

**피싱 사이트 검사**:
- 타이포스쿼팅 탐지 (유명 사이트와 85% 이상 유사한 도메인)
- 긴급성 강조 표현 탐지 (3개 이상 사용 시 의심)
- 신규 도메인 위험도 평가 (30일 이내)
- 사업자 정보 부족 탐지
- SSL 인증서 검증
- 리다이렉트 체인 추적 및 분석

**리뷰 신뢰도 분석**:
- AI 기반 텍스트 분석 (Claude 3.5 Sonnet 사용)
- 과도한 긍정 표현 탐지 (2개 이상 사용)
- 연속 리뷰 패턴 분석 (5분 내 3개 이상)
- 비현실적 배송/가격 표현 탐지
- 90% 이상 5점 리뷰 패턴 분석
- 배치 처리로 효율적인 분석 (5개씩 묶어서 처리)

**웹 크롤링 분석**:
- 의심 키워드 탐지
- 가격 적정성 분석
- 기술적 분석 (SSL, 도메인 연령)
- 콘텐츠 품질 분석

### 2.4. 사용자 인증 및 관리 시스템 ✅

**회원가입/로그인**: 이메일 기반 계정 생성
- 이메일, 비밀번호, 사용자명, 전화번호 필수 입력
- SMS 인증 필수 (6자리 인증번호, 3분 만료)
- SMS 레이트 리밋 (5회/분)
- JWT 토큰 기반 인증 (7일 만료)

**비밀번호 재설정**: 이메일 기반 비밀번호 재설정
- Gmail SMTP를 통한 재설정 링크 발송
- 토큰 기반 재설정 시스템

**관리자 페이지**: 
- 신고 관리 (승인/거부, 삭제)
- 쇼핑몰 관리 (이름 수정, 삭제, 병합)
- 사용자 관리
- 커뮤니티 게시글/댓글 관리
- 통계 대시보드 (차트 기반 데이터 시각화)

### 2.5. 커뮤니티 기능 ✅ (신규)

**게시판 기능**: 사용자 간 정보 공유 게시판
- 게시글 작성/수정/삭제 (회원 전용)
- 게시글 목록 조회 (최신순 정렬)
- 게시글 상세 조회 (조회수 자동 증가)
- 좋아요 기능 (중복 방지)
- 댓글 작성/삭제 (회원 전용)
- 제목 2-100자, 내용 10-1000자 제한
- 댓글 1-500자 제한

**권한 관리**:
- 본인 게시글/댓글만 수정/삭제 가능
- 관리자는 모든 게시글/댓글 관리 가능

### 2.6. 다크/라이트 테마 지원 ✅ (신규)

**테마 시스템**:
- 라이트 모드 / 다크 모드 / 시스템 설정 자동 감지
- LocalStorage 기반 테마 설정 저장
- 테마 토글 버튼 제공
- Tailwind CSS 기반 다크 모드 지원

## 7. 프로젝트 성과 및 기대효과

### 7.1. 기술적 성과
- **현대적 웹 기술 스택**: React 18.3.1 + TypeScript 5.5.4 + Vite 5.4.0 + Supabase 기반의 확장 가능한 아키텍처
- **AI 기반 분석 시스템**: Claude 3.5 Sonnet을 활용한 가짜 리뷰 탐지 및 객관적 신뢰도 평가
- **사용자 중심 설계**: shadcn/ui 기반 직관적인 UI/UX, 다크/라이트 테마 지원, 모바일 최적화
- **확장 가능한 아키텍처**: 라우터 분리 구조, 서비스 레이어 분리, RESTful API 설계
- **데이터베이스 설계**: 14개 테이블로 구성된 정규화된 데이터베이스 스키마
- **보안 강화**: JWT 인증, SMS 인증, 레이트 리밋, XSS 방지, 파일 업로드 검증
- **성능 최적화**: AI 분석 결과 캐싱, 배치 처리, 웹사이트 타이틀 캐싱
- **관리자 시스템**: Recharts 기반 통계 대시보드, 차트 시각화

### 7.2. 구현된 기능 성과
- **쇼핑몰 분석 시스템**: URL 정규화, 웹 스크래핑, 피싱 탐지, SSL 검증, 리다이렉트 추적
- **커뮤니티 시스템**: 게시판, 댓글, 좋아요 기능 완전 구현 (2025년 1월 신규 추가)
- **사용자 인증**: SMS 인증 필수 회원가입, 비밀번호 재설정, JWT 기반 인증
- **피해 사례 제보**: 파일 업로드, 상태 관리, 카테고리 분류
- **AI 분석**: 배치 처리로 최적화된 가짜 리뷰 탐지 시스템
- **관리자 페이지**: 통계 대시보드, 신고/쇼핑몰/커뮤니티 관리 기능

### 7.3. 사회적 기대효과
- **소비자 보호**: 온라인 쇼핑 피해 예방 및 신뢰도 정보 제공
- **투명성 확보**: 쇼핑몰 정보의 투명한 공개 및 공유
- **집단지성 활용**: 사용자 참여를 통한 피해 사례 데이터베이스 구축
- **커뮤니티 활성화**: 사용자 간 정보 공유 및 소통 플랫폼 제공 (신규)
- **데이터 기반 의사결정**: AI 및 통계 분석을 통한 객관적 평가 제공
