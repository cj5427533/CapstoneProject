## 1. 프로젝트 소개

### 1.1 "여기몰까"란?

**여기몰까**는 온라인 쇼핑몰의 신뢰도를 분석하고, 피해 사례를 공유할 수 있는 플랫폼입니다.

> **쉽게 말하면**: "이 쇼핑몰 믿을 만한가요?" 라는 질문에 답을 제공하는 서비스입니다.

### 1.2 왜 만들었나요?

- 온라인 쇼핑이 많아지면서 신뢰할 수 없는 쇼핑몰로 인한 피해가 증가
- 새로운 쇼핑몰 이용 전에 신뢰도를 확인할 방법 부족
- 피해 사례를 다른 사람들과 공유하여 예방하는 것이 목표

### 1.3 주요 가치

✅ **투명성**: 쇼핑몰 정보를 객관적으로 공개  
✅ **안전성**: AI와 집단지성을 통해 위험을 사전 탐지  
✅ **공익성**: 소비자 보호를 위한 비영리적 접근

## 2. 핵심 기능 설명

### 2.1 쇼핑몰 신뢰도 분석 🔍

**무엇을 하나요?**
- 사용자가 쇼핑몰 URL을 입력하면, AI가 여러 항목을 분석합니다
- 분석 결과를 0~100점의 점수로 보여줍니다
- 안전(초록), 주의(노랑), 의심(주황), 위험(빨강) 4단계로 분류합니다

**어떻게 분석하나요?**
1. **피싱 사이트 검사**
   - 도메인 연령 확인 (너무 새로 만들어진 사이트는 의심)
   - SSL 인증서 검증 (보안 연결 확인)
   - 유명 사이트와 비슷한 도메인명인지 확인 (타이포스쿼팅 탐지)
   - 긴급성을 강조하는 표현이 많은지 확인 ("지금 바로!", "마감 임박!" 등)

2. **리뷰 신뢰도 분석**
   - 가짜 리뷰 패턴 탐지 (AI 기반)
   - 과도한 긍정 표현 분석
   - 리뷰 작성 시간 패턴 분석 (5분 내 연속 리뷰 등)


### 2.2 피해 사례 제보 시스템 📋

**무엇을 하나요?**
- 실제 피해를 경험한 사용자들이 제보할 수 있습니다
- 7가지 카테고리로 분류됩니다:
  - 배송 문제
  - 상품 불일치
  - 환불 문제
  - 고객 서비스
  - 사기/피싱
  - 품질 문제
  - 기타

**어떻게 사용하나요?**
1. 회원가입 및 로그인 후, 제보가 가능합니다.
2. 증빙 자료를 첨부할 수 있습니다 (최대 10개, 사진만 가능, 10MB 이하)
3. 관리자가 검토 후 승인/거부 결정합니다

**중요한 점:**
- 제보는 즉시 공개되지 않으며, 관리자 검토 후 승인되어야 합니다
- 거짓 제보는 삭제될 수 있습니다

### 2.3 사용자 평점 및 리뷰 ⭐

**무엇을 하나요?**
- 쇼핑몰 이용 경험을 바탕으로 별점(1~5점)과 리뷰를 남길 수 있습니다
- 작성하면 사용자명이 표시됩니다.
- 몇몇 리뷰들의 조작, 거짓된 가능성에 대비해 리뷰 분석기능에 사용됩니다.

### 2.4 커뮤니티 기능 💬

**무엇을 하나요?**
- 사용자들이 정보를 공유하고 소통할 수 있는 게시판입니다
- 게시글 작성/댓글 작성은 회원 전용입니다
- 좋아요 기능이 있어 유용한 정보를 추천할 수 있습니다

### 2.5 관리자 시스템 👨‍💼

**무엇을 하나요?**
- 전문 관리자가 제보 내용을 검토합니다
- 쇼핑몰 정보를 수정하거나 병합할 수 있습니다
- 통계 대시보드를 통해 서비스 현황을 확인합니다

## 3. 사용 방법 가이드

### 3.1 쇼핑몰 검색하기

**손님께 설명하는 방법:**

1. **홈페이지 접속**
   - "여기몰까" 홈페이지에 접속합니다

2. **URL 입력**
   - 확인하고 싶은 쇼핑몰의 주소를 입력합니다
   - 예시: `example.com` 또는 `https://example.com`
   - `https://`를 붙이지 않아도 자동으로 처리됩니다

3. **검색 실행**
   - 검색 버튼을 누르면 분석이 시작됩니다
   - 결과는 몇 초 내에 나옵니다

4. **결과 확인**
   - 신뢰도 점수와 색상 표시를 확인합니다
   - 상세 분석 리포트를 읽어봅니다
   - 피해 사례 제보 건수를 확인합니다
   - 사용자들의 평점과 리뷰를 확인합니다

### 3.2 피해 사례 제보하기

**손님께 설명하는 방법:**

1. **제보 페이지 접속**
   - 쇼핑몰 검색 결과 페이지에서 "피해 사례 제보" 버튼을 클릭합니다

2. **제보 작성**
   - 카테고리를 선택합니다 (배송 문제, 환불 문제 등)
   - 제보 내용을 상세히 작성합니다
   - 증빙 자료를 첨부합니다 (선택사항)
     - 계약서, 입금 내역, 고객센터 대화 기록 등
     - 사진 파일만 가능 (PNG, JPG)
     - 최대 10개, 각 10MB 이하

3. **제출**
   - 제보를 제출하면 관리자 검토를 기다립니다
   - 승인되면 쇼핑몰 분석 결과에 반영됩니다

### 3.3 회원가입하기

**손님께 설명하는 방법:**

1. **회원가입 버튼 클릭**
   - 홈페이지 우측 상단의 "회원가입" 버튼을 클릭합니다

2. **정보 입력**
   - 이메일, 비밀번호, 사용자명, 전화번호를 입력합니다
   - 모든 항목은 필수입니다

3. **SMS 인증**
   - 전화번호로 6자리 인증번호가 발송됩니다
   - 3분 이내에 인증번호를 입력해야 합니다
   - 분당 5회까지만 요청 가능합니다

4. **가입 완료**
   - 인증이 완료되면 자동으로 로그인됩니다
   - 회원 전용 기능을 사용할 수 있습니다

**중요 사항:**
- SMS 인증은 필수입니다 (보안을 위해)
- 같은 전화번호로 분당 5회까지만 인증번호를 요청할 수 있습니다
- 인증번호는 3분 후 만료됩니다

## 4. 주요 화면 설명

### 4.1 홈페이지

**주요 구성 요소:**
- **검색창**: 쇼핑몰 URL 입력
- **미리보기**: 검색창에 입력하면 실시간으로 쇼핑몰 정보 미리보기 제공
- **주의가 필요한 페이지 Top 5**: 피해 사례 제보가 많은 쇼핑몰 목록
- **고평점 페이지 Top 5**: 평균 평점이 높은 쇼핑몰 목록

### 4.2 검색 결과 페이지

**주요 구성 요소:**
- **신뢰도 점수 표시**: 큰 원형 게이지로 0~100점 표시
- **신호등 표시**: 안전(초록), 주의(노랑), 의심(주황), 위험(빨강)
- **상세 분석 리포트**:
  - 피싱 사이트 검사 결과
  - 리뷰 신뢰도 분석 결과
  - 쇼핑몰 위험도 분석 결과
- **피해 사례 제보 목록**: 승인된 제보만 표시
- **사용자 평점 및 리뷰**: 별점과 리뷰 목록

### 4.3 피해 사례 제보 페이지

**주요 구성 요소:**
- **단계 표시기**: 1단계(카테고리 선택) → 2단계(내용 작성) → 3단계(증빙 첨부)
- **카테고리 선택**: 7가지 카테고리 중 선택
- **내용 작성**: 상세한 피해 내용 작성
- **파일 업로드**: 드래그 앤 드롭 또는 클릭으로 파일 첨부

### 4.4 커뮤니티 페이지

**주요 구성 요소:**
- **게시글 목록**: 최신순으로 정렬
- **게시글 작성 버튼**: 회원 전용
- **검색 기능**: 게시글 검색 (향후 추가 예정)

### 4.5 관리자 페이지

**주요 구성 요소:**
- **대시보드**: 통계 차트 (쇼핑몰 수, 신고 수, 사용자 수 등)
- **신고 관리**: 승인/거부/삭제 기능
- **쇼핑몰 관리**: 이름 수정, 삭제, 병합 기능
- **커뮤니티 관리**: 게시글/댓글 조회 및 삭제

## 5. 고객 문의 대응 가이드

### 5.1 서비스 이용 문의

**Q: "이 서비스는 무료인가요?"**
> A: 네, 완전 무료입니다. 회원가입도 무료이며, 모든 기능을 무료로 이용하실 수 있습니다.

**Q: "회원가입이 필수인가요?"**
> A: 아니요, 비회원도 쇼핑몰 검색, 평점/리뷰 작성, 피해 사례 제보가 가능합니다. 다만 커뮤니티 게시글 작성은 회원 전용입니다.

**Q: "SMS 인증이 왜 필요한가요?"**
> A: 보안을 위해 회원가입 시 본인 확인을 위해 SMS 인증이 필요합니다. 인증번호는 3분 후 만료되며, 분당 5회까지만 요청 가능합니다.

### 5.2 신뢰도 분석 관련 문의

**Q: "신뢰도 점수는 어떻게 계산되나요?"**
> A: AI 분석, 피해 사례 제보 건수, 사용자 평점, SSL 인증서 여부, 도메인 연령 등을 종합적으로 고려하여 계산됩니다. 점수가 낮다고 해서 무조건 사기 사이트는 아니며, 참고 자료로 활용하시기 바랍니다.

**Q: "분석 결과가 잘못된 것 같아요"**
> A: 분석은 여러 요소를 종합하여 자동으로 이루어지므로, 일부 쇼핑몰에서 오판이 있을 수 있습니다. 피해 사례 제보나 평점을 통해 정확한 정보를 공유해주시면 다른 사용자들에게 도움이 됩니다.

**Q: "제 쇼핑몰이 의심/위험으로 표시되는데 해결 방법이 있나요?"**
> A: 쇼핑몰 운영자분께서는 SSL 인증서를 설치하고, 사업자 정보를 명확히 표시하며, 고객 서비스를 개선하시면 신뢰도가 향상될 수 있습니다. 그러나 본 서비스는 일반 사용자들이 피해 사례를 공유하는 플랫폼이므로, 운영자와 직접적으로 연락을 드리지는 않습니다.

### 5.3 피해 사례 제보 관련 문의

**Q: "제보 후 얼마나 걸리나요?"**
> A: 관리자 검토 후 승인/거부가 결정됩니다. 일반적으로 1~2일 내에 처리되며, 승인된 제보만 검색 결과에 표시됩니다.

**Q: "제보를 삭제하고 싶어요"**
> A: 본인이 작성한 제보는 마이페이지에서 삭제할 수 있습니다. 회원이 아니시라면 고객센터로 문의해주세요.

**Q: "거짓 제보를 봤어요"**
> A: 신고하기 기능을 통해 관리자에게 알려주시면, 관리자가 검토 후 해당 제보를 삭제할 수 있습니다.

### 5.4 기술적 문의

**Q: "모바일에서도 사용 가능한가요?"**
> A: 네, 모바일, 태블릿, 데스크톱 모든 기기에서 사용 가능합니다. 반응형 디자인으로 모든 화면 크기에 최적화되어 있습니다.

**Q: "다크 모드가 있나요?"**
> A: 네, 다크 모드와 라이트 모드를 선택할 수 있습니다. 우측 상단의 테마 토글 버튼을 클릭하시면 전환할 수 있습니다.

**Q: "검색이 안 돼요"**
> A: 다음을 확인해주세요:
> - 올바른 URL 형식인지 확인 (예: example.com)
> - 인터넷 연결 상태 확인
> - 브라우저 캐시 삭제 후 다시 시도
> - 문제가 지속되면 고객센터로 문의

## 6. FAQ (자주 묻는 질문)

### 6.1 서비스 이용 관련

**Q: 회원가입 없이도 모든 기능을 사용할 수 있나요?**
> A: 네, 비회원도 쇼핑몰 검색, 평점/리뷰 작성, 피해 사례 제보가 가능합니다. 커뮤니티 게시글 작성만 회원 전용입니다.

**Q: 회원가입 시 개인정보는 안전한가요?**
> A: 네, 개인정보는 암호화되어 저장되며, 피해 사례 제보 시에도 익명으로 제보할 수 있습니다. 비밀번호는 해시 암호화되어 저장됩니다.

**Q: 비밀번호를 잊어버렸어요**
> A: 로그인 페이지 하단의 "비밀번호 찾기" 링크를 클릭하시면, 이메일로 비밀번호 재설정 링크를 받으실 수 있습니다.

### 6.2 신뢰도 분석 관련

**Q: 신뢰도 점수가 낮은 쇼핑몰은 무조건 사기인가요?**
> A: 아니요. 점수는 여러 요소를 종합한 참고 자료이며, 낮은 점수가 반드시 사기를 의미하지는 않습니다. 다만 주의가 필요하다는 신호로 이해하시면 됩니다.

**Q: 신뢰도 점수는 얼마나 자주 업데이트되나요?**
> A: 피해 사례 제보나 평점이 추가될 때마다 실시간으로 업데이트됩니다. AI 분석 결과는 24시간 캐시되어 있으나, 새로운 정보가 들어오면 즉시 반영됩니다.

**Q: 우리 쇼핑몰 점수를 올리고 싶어요**
> A: SSL 인증서 설치, 사업자 정보 명확히 표시, 고객 서비스 개선 등을 통해 신뢰도를 높일 수 있습니다. 또한 실제 이용자들이 좋은 평점을 남기면 점수가 향상됩니다.

### 6.3 피해 사례 제보 관련

**Q: 증빙 자료는 필수인가요?**
> A: 아니요, 선택사항입니다. 다만 증빙 자료가 있는 제보일수록 더 높은 신뢰도를 받아 관리자 승인 가능성이 높아집니다.

**Q: 제보 내용을 수정할 수 있나요?**
> A: 승인되기 전까지는 수정 가능합니다. 승인된 제보는 삭제 후 새로 작성해야 합니다.

**Q: 익명으로 제보할 수 있나요?**
> A: 비회원으로 제보하시면 익명으로 제보됩니다. 회원으로 제보하시면 사용자명이 표시됩니다.

### 6.4 기술적 문제 관련

**Q: 검색 결과가 나오지 않아요**
> A: 다음을 확인해주세요:
> - URL 형식이 올바른지 확인 (예: example.com)
> - 인터넷 연결 상태 확인
> - 일부 쇼핑몰은 접근이 제한될 수 있습니다

**Q: 파일 업로드가 안 돼요**
> A: 다음을 확인해주세요:
> - 파일 형식이 PNG 또는 JPG인지 확인
> - 파일 크기가 10MB 이하인지 확인
> - 최대 10개까지만 업로드 가능합니다

**Q: SMS 인증번호가 오지 않아요**
> A: 다음을 확인해주세요:
> - 전화번호를 올바르게 입력했는지 확인
> - 분당 5회까지만 요청 가능합니다 (레이트 리밋)
> - 스팸 메시지함도 확인해주세요
> - 문제가 지속되면 고객센터로 문의해주세요
